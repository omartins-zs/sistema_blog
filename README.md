## 🏗️ ARQUITETURA DO PROJETO

- **Tipo:** 🧱 Monólito
- **Descrição:** O projeto utiliza o padrão MVC (Model-View-Controller) do CodeIgniter, onde o backend (PHP) e o frontend (HTML/CSS/JS renderizado via Views) coexistem na mesma base de código.

---

## 🔥 PRÉ-REQUISITOS

- PHP 7.4+
- MySQL 5.7+
- Servidor Web (Apache/Nginx)
- Docker & Docker Compose (Recomendado para ambiente local)

---

## 🚀 TECNOLOGIAS UTILIZADAS

- **Linguagem:** PHP
- **Framework:** CodeIgniter 3
- **Banco de Dados:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 4
- **Bibliotecas:** jQuery, DataTables, OwlCarousel, AOS, Waypoints
- **Padrões:** MVC, Clean Code

---

## 🔨 FUNCIONALIDADES

- [x] Listagem dinâmica de posts e categorias
- [x] Sistema avançado de "Dark Mode"
- [x] Busca em tempo real de artigos
- [x] Painel Administrativo (Admin) protegido por login

## 💻 COMANDOS

### Via Docker (Recomendado)

```bash
# Subir os containers do projeto
docker-compose up -d

# Acessar a aplicação
# Abra http://localhost no seu navegador
```

### Tradicional (Laragon / XAMPP)

```bash
# 1. Clone o repositório na pasta www ou htdocs
git clone https://github.com/omartins-zs/sistema_blog.git

# 2. Importe o banco de dados
# Utilize o arquivo `docker/mysql/init.sql` no seu SGBD

# 3. Acesse via localhost
# http://localhost/sistema_blog
```

> ⚠️ Estes são comandos básicos. Verifique no projeto arquivos como:
> README.md, COMO_EXECUTAR.md ou docs/ para instruções completas.
